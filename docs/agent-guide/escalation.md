# 何时停下请求用户介入

> 以下情况必须暂停并向用户确认，**不要自行决策**。

## 必须停下

- 需要用户提供真实凭据、API 地址或测试环境
- 需要删除不可恢复的数据
- 外部服务不可用，无法完成验证
- 方案会改变 V1 产品边界或数据格式（见 [`scope.md`](scope.md)）
- 发现其他 agent 留下的修改与当前任务冲突，无法判断如何处理
- 需要执行 AGENTS.md 铁律 4 禁止的 Git 操作
- 需求模糊，无法确定实现方式

## 提问方式

停下时提供：

1. **现状**：当前进展到哪一步
2. **卡点**：具体是什么问题
3. **选项**：至少两个可选方案（如果适用）
4. **建议**：你倾向哪个方案，为什么
5. **影响**：每个方案的代价

## 不要停下的小事

- 代码风格选择（遵循 `.editorconfig` 和现有代码）
- 变量命名（遵循现有代码风格）
- 文件组织（遵循现有目录结构）
- 测试写法（参考现有 `*_test.go`）

这些按仓库已有约定自行决定，在 CHANGELOG 里说明即可。
